# Alpha issues

One file per work item, in execution order. The same items will exist as GitHub issues under the "Alpha" milestone; these files are the in-repository copy. Each file states its gate and whether it may be dropped if scope needs to shrink (see `docs/alpha.md`).

GitHub issue numbers are not known until the issues are created. Until then these files are named `A1-measurement.md`, `A2-recovery.md` and so on; once the corresponding GitHub issue exists, each file is renamed to `NN-slug.md` (matching `docs/phase0/issues/`'s convention), where `NN` is that issue's number.
